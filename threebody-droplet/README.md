# 水滴 · 末日之战 — three.js 实时演出

《三体 Ⅱ · 黑暗森林》末日之战的实时渲染再现。一枚 3.5 米长的探测器「水滴」穿过联合舰队两千艘恒星级战舰的方阵，三十分钟后，人类太空舰队全军覆没。

纯 three.js（r180）单页，无外部素材：星空、木星、战舰、爆炸、尾迹、木星大红斑全部程序化生成。

## 运行

ES module + importmap 不能走 `file://`，起一个静态服务器即可：

```bash
cd threebody-droplet
python3 -m http.server 8777
# 打开 http://127.0.0.1:8777/index.html
```

或 `npx serve .`。建议全屏 + 耳机。

## 技术要点

- **2000 艘战舰 / 三个舰级**：驱逐舰（1.0×）、巡洋舰（1.26×，侧舷武器舱 + 加高舰桥）、旗舰（1.62×，宽肩甲板 + 指挥塔 + 外侧推进舱），按 10×10 分队排布——分队中心是旗舰，外围是巡洋舰，其余是驱逐舰。每级一套 `InstancedMesh`，全都是一块 draw call。单舰约 40 个部件（六面棱柱舰体、后掠翼板、背脊、舰桥、炮塔、引擎钟形喷口、天线、凸起细节），约 700 三角面；装甲板细节由**三向投影（triplanar）程序化纹理**提供——板缝、检修口、铆钉、锈迹，按物体空间投影，任意朝向都不会拉伸。舰体额外注入菲涅尔边缘冷光，从黑底里勾出轮廓。被击毁的舰体不删除，而是随机姿态压扁、烧黑，在残骸镜头里当碎片用。
- **水滴外形**：母线由「正弦胖体 + 椭圆鼻尖」拼成——末端 10% 收成圆弧过渡的圆头，不是针尖，贴合原著里「一滴完美水银」的轮廓。
- **水滴镜面**：`LatheGeometry` 生成水滴母线，自定义 shader 采样 768 的实时 `CubeCamera` 立方体贴图（关 mipmap，避免曲面微分把反射糊成磨砂），`R = reflect(-V, N)` 纯反射。

  关键一点：**反射要压暗到 0.46，再叠一道跟随光源的窄高光**。不压暗的话，映出来的星空和球外星空一样亮，视觉上就成了「透明玻璃球里透出星星」；压暗 + 高光之后才是「实心抛光金属」。高光用 `N·H` 的两个指数项（42 / 190）合成，既有一片宽反光又有一个锐点。
- **爆炸**：三层结构——等离子火球（46 个球壳网格，自定义 shader 做「中心白热、边缘橙红」的体积感）＋ 2.6 万粒子碎片（逐粒颜色/尺寸/寿命）＋ 闪光 sprite 与冲击波环，全部对象池复用，爆炸时零 GC。
- **击中时刻表**：开机时把水滴的攻击曲线采样 900 点，为每艘舰算出「最近路径点时间 + 距离/520」作为毁灭时刻并排序，运行时按时间指针出队，所以火线形状永远和屏幕上的水滴轨迹对齐。
- **木星**：程序化条带 + 大红斑 + 湍流，外面套一层大气边缘光（菲涅尔 + 向阳/背阳分色），轮廓不再是硬边球。
- **镜头**：所有分镜叠加了随距离缩放的手持微漂（位移 + 微滚转），不是死板的轨道机。
- **后处理**：`EffectComposer` → `UnrealBloomPass` → 自定义调色（暗角、色散、胶片颗粒）→ `OutputPass`（ACES）。
- **性能**（Retina 1600×900 实测，攻击段最重）：优化前 62 fps → 优化后 93–115 fps。做法：
  1. **分辨率封顶 + 自适应**：`devicePixelRatio=2` 时原来按 1.8 渲染，缓冲 450 万像素；现在封顶 1.6，并在掉到 54 fps 以下时自动降到 0.72×（≈1.15×），主循环里每 1.4 秒评估一次。
  2. **反射代理**：`CubeCamera` 每 3 帧要重画 6 遍场景，两千艘全模型是最大开销；另建一套约 40 面的低模舰体，只在立方图渲染时替换，镜面里看不出区别，立方图开销从 +13 fps 降到 +5 fps。
  3. **立方图里不画粒子**（粒子满屏叠加，6 遍填充很贵），分辨率 768 → 512。
  4. **泛光降到 0.72 分辨率**；粒子池 2.6 万 → 1.8 万，无存活粒子时整段跳过更新与显存上传。
  5. 31 秒后不再齐射（方阵内部的交叉光束既不合理也拖累填充）。
